# 🍄 Super Mario (Python)

### 📝 Description

This is a remake of the classic Super Mario game, built from scratch using **Python** and the **Pygame** library. The project features a complete environment with smooth animations, classic sound effects, and multiple game states.


### Key features:

* 🏃‍♂️ **Animations:** Fluid movement for Mario, including walking, jumping, and turning.
* 🧱 **Interactive Environment:** Animated "Lucky Blocks", breakable objects, and collectible coins.
* 🍄 **Entities:** Working mushroom animations and enemy logic.
* 🎵 **Sound & Music:** Classic themes (Overworld, Underground, Underwater) and jump sound effects.
* ⚙️ **Game Menu:** Custom settings, "About" section, and control schemes.


### 🎮 How to run the game?

1. **Install Python** Make sure you have Python 3.x installed on your system. You can download it from [python.org](https://www.python.org/).

2. **Install Dependencies** The game requires the `pygame` library. Open your terminal/cmd and run:
   ```bash
    pip install pygame
   
3. **Launch the Game** Navigate to the project folder and run the main script:
   ```bash
    python MARIO_UA.py


### ⌨️ Controls:

* Arrows / WASD - Movement;
* Space - Jump;
* P - Pause game;
* Esc - Return to Menu.


### Project Structure:

MARIO_UA.py — The main entry point of the game.

images for animation/ — Spritesheets for character movement.

luckyblock_animation/ & mashroom_animation/ — Object-specific animations.

smb-*.mp3 — Background music tracks for different levels.
